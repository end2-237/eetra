# ⚡ Guide Rapide - Nouvelles Fonctionnalités

## 🎯 Accès Facile

### Les Contrôles Flottants (Toujours Visibles!)

Quand vous **survolez** un bloc de texte, vous verrez une barre de contrôle à droite avec:

```
┌─────────────────────────┐
│  ◄─ G ◄─ C ─► D ─► J  │  ← Alignement
│                         │
│  ↑    ↓    🗑            │  ← Déplacement & Suppression
└─────────────────────────┘
```

**Boutons:**
- **G** = Aligner à gauche
- **C** = Centrer
- **D** = Aligner à droite  
- **J** = Justifier
- **↑** = Monter le bloc
- **↓** = Descendre le bloc
- **🗑** = Supprimer le bloc

---

## 📍 Où Trouver Quoi

### Alignement et Mouvement
**Location:** Barre flottante à droite de chaque bloc (au survol)

### Couleur & Police
**Location:** Panneau de droite → Section "Page de garde"
- Police titres: Choisissez parmi 12 options
- Police corps: Choisissez parmi 12 options
- Confidentialité: 6 presets + personnalisé

### Listes Personnalisées
**Location:** Barre flottante du bloc (pour listes)

### Formes Décoratives  
**Location:** Barre flottante du bloc "Séparateur"

## 🎨 Actions Courantes

| Action | Étapes |
|--------|--------|
| **Centrer un titre** | Survolez H1/H2 → Clic C |
| **Aligner texte à droite** | Survolez paragraphe → Clic D |
| **Monter un bloc** | Survolez bloc → Clic ↑ |
| **Descendre un bloc** | Survolez bloc → Clic ↓ |
| **Supprimer un bloc** | Survolez bloc → Clic 🗑 |
| **Changer une liste** | Survolez liste → Sélectionnez style |
| **Ajouter un séparateur** | Bibliothèque → "Séparateur" |
| **Changer les polices** | Panneau droit → Police titres/corps |
| **Marquer comme confidentiel** | Panneau droit → Confidentialité |

## 🔍 Interface Reference

### Panneau de Droite (Propriétés)
```
┌─ Page de garde
│  ├─ Titre
│  ├─ Sous-titre
│  ├─ Ref
│  ├─ Destination
│  └─ Confidentialité (6 presets)
├─ Formatage rapide (Guide)
├─ Bibliothèque de Blocs
│  ├─ Titres (H1-H4)
│  ├─ Listes
│  ├─ Structure
│  ├─ Données (Tableaux, KPI, Graphiques)
│  ├─ Visuel (Images)
│  └─ Juridique
└─ Style du Document
   ├─ Police titres (12 options)
   └─ Police corps (12 options)
```

### Barre Flottante par Bloc (Au Survol)
```
┌──────────────────────────────┐
│ [G] [C] [D] [J]              │  ← Alignement (texte seulement)
├──────────────────────────────┤
│ [↑] [↓] [🗑]                 │  ← Mouvement & Suppression
└──────────────────────────────┘
```

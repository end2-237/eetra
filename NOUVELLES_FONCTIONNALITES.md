# 🎨 Nouvelles Fonctionnalités d'Édition - EETRA 2.0

## ✨ Fonctionnalités Activées

### 1. **Alignement du Texte**
Tous les blocs de texte peuvent maintenant être alignés selon vos besoins.

**Comment l'utiliser:**
- Survolez un bloc de texte (paragraphe, titre, citation, etc.)
- Cliquez sur les icônes d'alignement qui apparaissent à droite:
  - **G** = Gauche
  - **C** = Centre  
  - **D** = Droite
  - **J** = Justifié

### 2. **Styles de Texte**
Appliquez du gras, de l'italique et du soulignement directement.

**Comment l'utiliser:**
- Sélectionnez un bloc de texte
- Les options de style apparaissent dans le panneau "Formatage rapide"
- Cliquez sur Gras (**B**), Italique (*I*), ou Souligné (U)

### 3. **Couleurs et Polices**
Modifiez la couleur du texte et choisissez parmi 24 polices disponibles.

**Où trouver:**
- **Polices:** Panneau de droite → "Page de garde" → "Police titres" ou "Police corps"
- **Couleurs:** Barre de contrôle de bloc (sélecteur de couleur)

### 4. **Taille de Police Variable**
Ajustez la taille de votre texte de 8px à 48px.

**Comment l'utiliser:**
- Dans le panneau de style du bloc
- Entrez la taille souhaitée

### 5. **Styles de Listes Personnalisés**

#### Listes à Puces
- Disc (●) - Standard
- Circle (○) - Cercle creux
- Square (■) - Carré

#### Listes Numérotées
- 1, 2, 3... - Chiffres arabes
- I, II, III... - Chiffres romains majuscules
- i, ii, iii... - Chiffres romains minuscules
- A, B, C... - Lettres majuscules
- a, b, c... - Lettres minuscules

### 6. **Insertion de Blocs Flexible**
Ajoutez des blocs à n'importe quel endroit, même au milieu d'une page vide.

**Comment l'utiliser:**
- Cliquez sur un type de bloc dans la "Bibliothèque de Blocs"
- Le bloc s'ajoute à la fin de la page
- Utilisez les boutons ↑ ↓ pour le déplacer

### 7. **Mouvement de Blocs (↑ ↓)**
Réorganisez vos blocs facilement.

**Comment l'utiliser:**
- Survolez un bloc
- Cliquez sur ↑ (monter) ou ↓ (descendre)
- Le bloc se déplace immédiatement

### 8. **Formes Décoratives**
Personnalisez vos séparateurs avec des formes.

**Formes disponibles:**
- Cercle (●)
- Rectangle (■)
- Ligne (—)

**Comment l'utiliser:**
- Créez un bloc "Séparateur"
- Surfez sur le bloc
- Les options de forme apparaissent

### 9. **Confidentialité Enrichie**
6 presets + texte personnalisé.

**Presets disponibles:**
- 🔴 Confidentiel
- 🔴 Strictement Confidentiel
- 🟠 Usage Interne
- 🟢 Public
- 🟣 Brouillon
- 🔵 Restreint

**Comment l'utiliser:**
- Panneau de droite → "Page de garde"
- Cliquez sur un preset OU entrez du texte personnalisé

## 🎯 Guide Rapide

### Scénario 1: Centrer un titre
1. Cliquez sur votre titre H1
2. Survolez le bloc jusqu'à voir les contrôles
3. Cliquez sur le bouton "C" pour centrer

### Scénario 2: Créer une liste personnalisée
1. Créez une "Liste numérotée"
2. Survolez le bloc
3. Les contrôles affichent les options de numérotation
4. Sélectionnez votre style (A, B, C ou I, II, III, etc.)

### Scénario 3: Réorganiser les contenus
1. Cliquez sur le bloc à déplacer
2. Utilisez les flèches ↑ ↓
3. Le bloc monte/descend sur la page

### Scénario 4: Ajouter une forme décorative
1. Créez un "Séparateur"
2. Survolez-le
3. Les options de forme (cercle, rectangle, ligne) apparaissent
4. Sélectionnez la taille et la couleur

## ⚙️ Paramètres Avancés

### Alignement du texte
L'alignement s'applique à:
- Paragraphes
- Titres (H1-H4)
- Sections
- Citations
- Clauses juridiques

### Styles personnalisés
Les styles s'appliquent indépendamment:
- Gras + Italique
- Gras + Souligné
- Tous les trois combinés

### Couleurs
Vous pouvez:
- Choisir parmi 6 couleurs prédéfinies
- Utiliser un sélecteur de couleur personnalisé
- Appliquer à du texte sélectionné ou à un bloc complet

## 🔧 Dépannage

**Les contrôles n'apparaissent pas?**
→ Survolez le bloc avec la souris

**Mes styles ne sont pas appliqués?**
→ Vérifiez que vous avez cliqué sur le bon bloc

**Je veux réinitialiser un style?**
→ Cliquez à nouveau pour basculer (ex: gras on/off)

### 2. 📊 ALIGNEMENT (4 OPTIONS)

```
Clic droit → Alignement

⬅️  Gauche      |  Texte aligné à gauche
⬆️  Centre      |     Texte centré
➡️  Droite      |              Texte à droite
↔️  Justifié    |   Texte justifié sur toute
                la largeur de la page
```

---

### 3. 📝 STYLES DE TEXTE (3 OPTIONS)

```
Clic droit → Style de texte

**Gras**      → Texte en gras
*Italique*    → Texte en italique
<u>Souligné</u> → Texte souligné
```

**Note:** Peuvent être combinés! (**_Gras italique_**)

## 🎬 DÉMO RAPIDE

### Scénario 1: Formater un titre
```
1. Cliquez droit sur le titre
2. Cliquez "Police" → Sélectionnez "Playfair Display"
3. Cliquez "Taille de police" → Sélectionnez "28px"
4. Cliquez "Couleur" → Sélectionnez "Bleu"
5. Cliquez "Alignement" → Centre

✨ Titre bleu, 28px, Playfair, centré!
```

### Scénario 2: Ajouter une forme
```
1. Cliquez "Ajouter Forme" (bas du panneau)
2. Sélectionnez "Cercle"
3. Choisissez couleur: Orange
4. Choisissez taille: Grand
5. Cliquez pour insérer

✨ Cercle orange décoratif ajouté!
```

### Scénario 3: Utiliser la barre flottante
```
1. Survolez un paragraphe
2. Cliquez "C" pour centrer
3. Cliquez "↓" pour descendre
4. Cliquez "🗑️" pour supprimer

✨ Paragraphe centré et déplacé!
```
